# Building-A-Dashboard-With-IBM-Cognos-Analytics-Project
IBM Cognos Analytics dashboard project exploring developer technology trends, programming language preferences, and respondent demographics through interactive data visualizations.


Project Overview

This project focuses on analyzing developer survey data using IBM Cognos Analytics to create interactive dashboards and data visualizations.

The objective was to explore current technology usage, future technology preferences, and demographic information among survey respondents.

Using IBM Cognos Analytics, I transformed survey data into visual representations to identify trends, compare technology preferences, and better understand the developer community.

This project was completed as part of the IBM Data Analyst Professional Certificate coursework.

Dataset
The project uses the Stack Overflow developer survey dataset provided through IBM Skills Network.

Dataset: Survey Data – Updated CSV

The dataset contains information about developers' current technology usage, future technology interests, education levels, age groups, and geographic locations.
Dashboard Structure
The dashboard consists of three separate sections, each designed to explore a different aspect of the survey data.
1. Current Technology Usage
This section explores the technologies developers currently use.

Visualizations include:
- Top 10 programming languages currently used (Bar Chart).
- Top 10 databases currently used (Column Chart).
- Top 10 platforms currently used (Word Cloud).
- Top 10 web frameworks currently used (Hierarchy Bubble Chart).
2. Future Technology Trends
This section explores the technologies developers are interested in working with in the future.

Visualizations include:
- Top 10 programming languages developers want to work with (Bar Chart).
- Top 10 databases developers want to work with (Column Chart).
- Top 10 platforms developers want to work with (Tree Map).
- Top 10 web frameworks developers want to work with (Hierarchy Bubble Chart).
3. Demographics
This section explores the demographic characteristics of survey respondents.

Visualizations include:
- Respondent distribution by age (Pie Chart).
- Respondent count by country (Map Chart).
- Respondent distribution by formal education level (Line Chart).
- Respondent count by age, classified by education level (Stacked Bar Chart).
